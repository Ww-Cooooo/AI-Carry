# 长期正式记忆（实例拥有）

- 格式：Markdown + 前置元数据（见 `core/schemas/asset-frontmatter.schema.md`）。
- 模板：`core/templates/memory/blank-memory.md`。
- 真源：Markdown 文件；本地索引/缓存只是派生物。

## 怎样找到一条记忆

正式小型索引只有 `instance/maps/domain-map.toml` 一份；先用低敏元数据命中路线，再按需读取对应正文。本说明不再维护第二张手工表，避免地图、正文和看板出现三份不同状态。

用户不需要说出准确标题、稳定 ID 或文件路径。日常表达先只和地图中的标题、摘要、触发语、别名、范围与条件比较；找到候选后才读取正文。模糊表达只有一个明显候选时，先用用户当前交流语言说出人能看懂的旧做法并问“是不是这个”，确认后再读取；多个不同候选会改变结果时才让用户选择。用户已明确点名旧做法或点击带稳定 ID 的动作时不重复确认。

## 规则

- 不存聊天全文、冗长日志或无价值琐事。
- 用户当前明确要求记住、修改或删除时，不重复确认同一内容；仍检查隐私位置、外发和不可逆后果。
- 任务命中后，当前用户选择的宿主模型／API可以取得完成任务所需的最小相关隐私正文；“相关”不授权发送给网站、邮件、MCP／插件、其他 Agent／人员、Git 或公开位置。API 密钥、密码、令牌、Cookie、私钥、恢复码和登录态不得写入记忆或提供给模型。
- 一次模型／宿主推断先只留在当前任务；Agent 在自然停点说明发现，用户选择“先观察”后才建立候选并允许以后累计验证证据，选择“不保存”或没有回应时，候选、信号和提醒都不持久保存。狭窄、可撤销、重复真实验证的低风险候选可以按实例政策更早进入复核，但用户明确确认具体内容和适用范围后才可试用或成为正式记忆；身份、隐私、安全、重要偏好和高影响内容还要完整说明风险。
- 当前有效内容与按需历史分开；条件不同的偏好保留条件分支，不互相覆盖。
- 低频但关键的内容不因长期未用而清理。
- 同类检索先看小型主题、对象、主张、范围和别名，再读取少量正文；不为合并加载全库。
- 沟通或工作习惯仍是 `kind=memory`，使用 `subtype=habit`；它必须写清适用范围、例外、来源和停止沿用方式，并可在看板“我的习惯”中纠正或停止使用。习惯仍只计一条记忆。
- 用户不必主动要求“形成记忆”。真实任务中出现重复习惯或重要纠正时，Agent 在自然停点先用用户当前交流语言说明未来用途并询问是否留下；用户只判断内容和范围，内部类型与路线由 Agent 处理。
- 普通记忆与召回继续使用文件地图。公版的记忆引擎升级方案暂时撤回；已有索引和用户自建检索层保留，Markdown 始终真源。
