# 路线图

## 1.0 基线

- 模板与实例统一生命周期；交流方式可随时调整，通用/领域方向在实例化确认后永久锁定。
- 三层渐进路由与 Markdown/TOML 正式资产。
- 提示词优先的通用宿主接入、开放式能力发现、接入回执、按需宿主档案、任务胶囊和来源保留回传。
- 宿主协作记忆的渐进盘点、去重、冲突处理和增量回流。
- 外部内容紧凑安全边界和高风险深层协议；当前模型可按任务需要处理普通隐私，秘密凭据永不入模，额外接收方单独授权，联网／递归任务有有限资源边界和安全回传。
- 学习内容保存前判断、同类候选元数据漏斗、风险分级验证／复核排序，以及由用户明确确认的可撤销低风险试用；风险策略不再授权正式资产。
- 能力／SOP 的可携带核心、按需宿主执行经验和真实任务证据成熟度。
- 来源／契约约束结果、正式多文件变更和学习证据共用一扇任务内验证门；只让经过验证的最终结果累计成功，不增加普通启动或用户回归负担。
- 时间、次数、风险、健康、状态、版本和恢复规则的统一触发注册表。
- 跨会话正式状态、稳定事件去重、最早时间聚合、非启动时间索引、极小唤醒胶囊和中断后定向恢复。
- 按真实需要使用跨 Agent 最小任务包；模型等级只作建议，不固定规划者和执行者身份。
- GitHub 链接与完整压缩包共用的 Agent 引导安装入口；安装后主动创建并验证可重建的桌面看板快捷方式，不要求 Git、终端或开发依赖。
- 面向普通用户的离线电脑端看板：按“总览、随身资产、待办与成长、迁移与安全、当前状态”组织内容，以行星系统作为品牌导航，并保留完整复制请求、分离的 GitHub 私有仓库脱敏备份与本地隐私迁移。
- 另一台电脑上的 1.0 完整恢复以固定五文件套件建立主体／隐私分离、逐文件清单和摘要校验基线；无隐私正文时仍保留 0 项隐私包，秘密在新环境重新配置。Windows 上已用虚构实例完成 1.0 生成—隔离恢复闭环。

## 1.1 增量

- 增加公开贡献说明、结构化问题模板和安全报告入口，让普通用户知道去哪里反馈，也让贡献回流继续经过私密开发真源与公开候选审查。
- 登记唯一官方公开更新源。只有用户主动要求检查时才联网；不后台检查、不自动下载、不强制升级，离线包继续使用同一发布清单与升级预览。
- 补齐压缩包安装入口和渐进路由触发语，使“先帮我判断方向”、任务状态、资产形成与可选模型协作能从极小地图稳定找到对应协议。
- 保持现有 Schema 与扩展接口兼容；从 1.0.0 升级时替换模板核心，迁移实例身份与长期治理排期，并保留记忆、能力、SOP、经验、待办、宿主档案、本地私密层和派生层。

## 1.2 私密资产可携带

- 增加按需私密资产目录：逻辑集合可携带，当前设备绝对路径绑定不迁移、不进 Git、不进普通启动。
- 外部课程、视频、账务附件等只有在用户明确登记后进入携带范围；系统不扫描整台电脑猜测。
- 导出前对目录、绑定、正式引用、管理根实际文件和最终清单做覆盖对账，缺项就停止完整结论。
- Migration Kit Schema 2.0 支持连续私密分卷与超大文件分块，保留小型实例五文件体验并兼容 1.0 旧套件。

## 后续按需

- 在真实资产规模和失败查询触发后，增加本地全文或混合检索派生层。
- 用不同能力水平和未来未知宿主继续真实跨会话验证，重点检查重复接入、档案匹配、宿主既有记忆规模和来源保持；发现通用协议不足时先改语义协议，宿主专用适配保持可选。跨系统实测不列入当前路线图和发布门禁。
- 根据长期治理 TODO 的周期性技术调研，改进记忆治理、一致性机制和 Agent 安全；这些研究平时不进入上下文，也不后台运行。
- 每个准备分享或上传的候选都从明确允许集合生成，不直接复制正在使用的个人实例；按实际候选文件集合复核个人资产、秘密凭据、临时材料和路径泄漏。
- 项目许可证已经确认为 Apache License 2.0；可分发候选必须同时包含根 `LICENSE`、第三方依赖、改写源码与随包字体的许可、版权和固定来源说明，并按准确候选集合重新复核许可证、版权署名和未登记二进制素材。
