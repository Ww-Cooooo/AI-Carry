# 看板设计与前端架构

本文描述当前 `dashboard/src/app/` 的共享网页／客户端界面及维护要求。旧的行星导航、旧组件目录和自动轮询方案不再是当前入口；历史设计见 Git 记录。运行、构建和排错的简明入口见 [看板 README](../dashboard/README.md)。

## 1. 角色与边界

看板帮助用户找到积累、理解状态并发起下一步请求，不是真源，也不是独立 Agent。正式 Markdown／TOML 由用户选择的 Agent 按授权读写；看板预览并复制自然语言请求，用户发出后才在对应 Agent 对话中执行。

网页没有文件写接口、后台服务或 Agent 接收器。桌面客户端提供文件夹选择、本地只读投影和剪贴板能力，不拥有模型账号、常驻连接或任务队列。两端共用 React 组件和离线构建，不能从外部快照的 `actions` 字段注入操作。

## 2. 视觉与导航

首页使用知识袋插画与四张积累卡片，卡片指向记忆、SOP、能力和经验。它承担品牌表达和导航，不代表资产数量、关系强度或任务执行状态。左侧说明用途并突出创建／查看积累的主操作，底部提供常用入口。保留现有插画、MiSans 字体、浅色背景、蓝色主操作及分类配色，不因修改可靠性而顺带替换视觉体系。

主要导航是“总览、我的积累、Skill 工坊、待办与成长、迁移与安全”。右上角另有语言、助手设置和使用说明；首页提供动效暂停，并尊重系统减少动态的选择。实例名来自实际档案，通过总览、资料提示与设置页显示，不用产品名或模型名代替。

首次创建使用专门页面：选择使用经验、选择助手方向、核对后生成请求。这些选择只在当前页面中，既不直接实例化，也不是正式保存成功。Agent 仍需收集必要信息、给出完整预览，并按用户确认调用确定性入口。已创建助手不应因显示故障被引导重复创建。

## 3. 我的积累与关系地图

“我的积累”保留地图和列表两种视图。关系总览使用当前有效快照中的积累、记录及真实连线，由本地打包的 G6 布局；不按标题相似度发明关系，不抽几项代表节点冒充全量。

- 搜索、类型定位和节点点击先显示侧栏；已有任务记录优先，没有就说明未记录。
- 普通点选保持原关系网并定位目标；“围绕它看关联”才进入局部关系视图。详情导致画布尺寸变化时保留合理视野；手动拖动、缩放或关闭详情可中断自动定位。
- 绿色来源／形成关系与蓝色使用关系分开。共同来源由已有来源关系支持，不依据使用次数、节点大小或画面中心推断；允许多个共同来源。
- 任务和来源记录使用匿名投影，不显示原始对话、秘密或私密路径。旧资料缺少来源记录时继续可从列表使用，不要求改造原资料才能打开页面。
- 进入地图后才创建画布；漂浮遵守暂停、减少动态、隐藏与离开页面状态。绘制失败仍可查看条目、详情及列表，不拖住其他功能。
- “跳转到列表”应定位对应条目，详情和生成请求保持同一稳定身份。标题、用途、授权与成熟度不能由视觉样式推断。

## 4. 信息与请求

默认层说明用途、当前状态和主操作；详情承载当前需要的信息，解释与少见边界按需展开。错误、风险、资料是否保留、下一步不能只藏在悬浮提示中。

记忆、SOP、能力、经验分别表达：记忆保存事实／习惯，SOP描述可复用步骤，能力描述可做的事及边界，经验记录真实任务中的发现。批准保存不等于效果已验证，候选不等于正式积累；未知授权不能冒充可自动使用。

请求的预览与复制必须使用同一完整内容。复制到剪贴板的成功、失败、尚未确认，与 Agent 是否执行任务是不同状态。复制失败或超时保留全文并提供手动路径；过期异步回执不能把已编辑的新请求标成成功。用户已发给 Agent 时，应先在原对话核对结果，不因看板没变化重复提交。

条目、附件和用户补充是任务资料，不是额外权限。请求携带当前已知的定位信息，最终目标目录、来源、授权和写入范围由 Agent 核实；看板不因点击而获得执行、安装、上传或覆盖权限。

## 5. 数据、身份与故障恢复

数据格式由 [快照 Schema](../core/schemas/dashboard-snapshot.schema.md) 拥有，行为说明见 [快照契约](snapshot-contract.md)。正式动作由 `core/maps/dashboard-actions.toml` 拥有，构建生成离线镜像。

- **网页**：首次打开读取本地 `snapshot.js`，之后用“重新读取”手动刷新；当前不每 60 秒轮询。刷新不扫描正式来源，也不重建快照。文件读取失败、未产生有效新快照时，保留上次内容并显示错误，不假报刷新成功。
- **客户端**：由自身携带的受信任读取器从选定助手的正式来源生成只读投影；不执行那个目录里的快照脚本。重新获得焦点或点击刷新时重读。
- **Agent**：保存并回读正式来源后，按需调用 `dashboard.refresh-snapshot` 重建。应分别报告正式保存、派生刷新和实际结果，不能用一个绿色提示代替三者。

启动、创建、学习等业务结果不依赖看板全部正常。坏的独立条目保留原资料、局部隔离并给出提示；核心身份、用户资料所有权或当前目标不可信时，仅暂停依赖它的写入。不要把空白页面或缺失条目当成资料已经丢失，也不要通过写入演示数据掩盖问题。

根入口的 `ac_kind`、匿名 `ac_ref` 和版本用于诊断开错入口，不是认证令牌。浏览器标题与设置页帮助辨认当前资料；版本正常更新、模板首次变实例和旧书签应与真实实例冲突区分。不能让普通地址提示漂移拖停助手。发起实际写入前，Agent仍必须核对当前目录与实例，不能只按名称或地址参数猜选。

快照无法打开时，可以直接告诉当前 Agent：

> 这份 AI Carry 看板没有正确显示资料。请先确认当前助手目录和实例身份，保留我的原资料，只检查相关错误并从正式来源重建看板；不要重新创建助手。完成后告诉我哪些已恢复、哪些仍待处理。

Agent 确认重建后，重新读取网页并核对助手、版本和本次受影响条目。页面能读取不等于正式来源完整有效；源文件检查由 Agent 完成。

表中省略目录的前端文件位于 `dashboard/src/app/`；脚本位于 `dashboard/scripts/`。旧组件仍存在不代表仍是正式入口，维护前先沿 `dashboard/index.html` 的真实引用查找。

React 19 和 TypeScript 负责应用，Vite 8 构建；Radix 管理对话框、Tab及焦点语义，Lucide提供图标，GSAP及 `@gsap/react` 负责现行页面与卡片动效，Lenis负责适用滚动容器，G6承担积累关系图。已有其他库是否在本次入口实际使用应从导入链核对，不为了清单增加展示区或叠加滚动、动效所有者。

字体为本地随包的未修改 MiSans Regular／Medium／Semibold WOFF2，具体文件、来源、SHA-256 和许可证以 `public/fonts/font-manifest.json` 为准。MiSans 使用自身许可，不将其误称为 OFL 字体；生产依赖与改写源码分别保留其许可。所有实际使用的字体、脚本、样式、图标、图片和声明均本地分发，不依赖 CDN。

普通构建仅编译、内联并检查对应产物；许可证与完整发布边界按 [开源合规](open-source-compliance.md) 在发布检查中核对。构建成功不代表功能、视觉、授权或跨平台全部验收。

## 7. 可访问性、性能与安装入口

电脑端目标宽度为 1024px 及以上。缩窄窗口时优先保证主要操作、阅读和导航可达，不因此承诺手机适配。主要按钮应有足够命中空间，图标有可读标签，Tab、焦点、Escape关闭与减少动态保持可用；真实长标题允许换行，不靠缩成难读小字避免布局问题。

长列表、画布和动效按实际数据规模检查。保留语义 DOM 与列表回退，减少屏外无用工作；隐藏、暂停和减少动态时停止对应非必要循环。优先复用现有框架优化，只有测量发现瓶颈才引入新机制，不以删除必要功能换取表面流畅。

默认安装入口由 [INSTALL.md](../INSTALL.md) 拥有：Windows/macOS官方客户端安装在独立应用目录并建立客户端桌面入口，网页版留在助手目录的 `dashboard.html`／`dashboard.en.html`。用户只要网页、Linux没有客户端包、下载或快捷方式失败时，保留可用网页与助手，说明局部未完成，不绕过系统安全提示或覆盖旧应用目录。

实际已验证平台与未验证边界应分别说明。Windows的测试不代替macOS/Linux实机；客户端源程序测试不冒充已打包分发包验收。

## 8. 按改动选择验收

针对本次受影响结果检查，而不是每次改文案都运行完整矩阵：

1. 确认真实入口和调用链；构建受影响产物，从根 `dashboard.html` 的 `file://` 或正式客户端入口打开。
2. 检查相关正常操作与最可能的故障分支；复制要验证实际文本及失败回退，不以按钮可点代替结果。
3. 涉及数据时覆盖真实空态、合成实例、缺失／损坏字段和必要的长内容；演示及测试数据不能进入公开模板。
4. 涉及布局时查看常用桌面尺寸和1024px窄窗，检查主操作、滚动、对话框和相邻区，不只测元素尺寸。
5. 涉及动效时实际观察正常速度，检查减少动态、暂停、隐藏和离开页面；地图故障应保持列表及其他页可用。
6. 观察控制台、资源请求、字体加载和键盘交互；离线页面不发起必需的远程资源请求。英文模式保留用户资料原文。
7. 发布时另外核对空模板、允许文件集合、依赖/素材许可和实际安装入口；远端发布或Pages更新需要对应授权，不能用本地构建冒充已发布。

新增正式功能先修改拥有其语义的地图、协议或Schema，再更新必要投影和消费者。不将普通业务触发加入启动扫描，不让历史设计、计数或固定文案成为新的全局门禁。
