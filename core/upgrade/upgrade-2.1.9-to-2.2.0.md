# 从 2.1.9 升级到 2.2.0

2.2.0 重新整理看板导航、摘要与详情，增加客户端读取超时和页面恢复。资料格式与已保存内容保持兼容；升级本身不删除、归档或重新批准任何积累。

## 保留什么

实例身份、偏好、记忆、SOP、能力、经验、Skill、专业工作区、本机绑定、私密资料和未知文件继续保留。既有分类移除与恢复、来源记录和真实关系仍可使用。安全的旧元数据由读取器兼容处理，不要求用户改写正文来适应界面；异常的可选记录只影响当前项。

## 怎样升级

按升级指南核对本版官方 Release、固定标签与文件，展示绑定当前实例的预览。用户确认后，在原目录按清单替换产品内容，并保留回退。随后核对身份与一项相关操作；看板刷新问题单独处理，不重建整个助手。

## 配套客户端

读取与原生恢复位于独立客户端中。应由安装 Agent 根据 `desktop/client-release.json` 并排安装 2.2.0 客户端、更新本助手的入口，并保留旧客户端；只更新助手目录不会更新正在运行的旧程序。安装目录里的 `dashboard.html` 仍可使用。

页面重新载入只恢复 AI Carry 窗口，不重启 Agent；未提交输入可能需要重填。整个程序或操作系统无响应时，仍需从程序外处理。Mac 包未签名、未完成实机验收；不得绕过系统安全提示。
