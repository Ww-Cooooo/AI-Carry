# 升级到 AI Carry 2.0.11

从看板“检查并升级 AI Carry”进入，或请当前 Agent 检查官方新版本。按 `core/guides/upgrade-guide.md` 展示预览、确认后升级；实例不需要安装开发依赖或运行母版的发布测试。

## 本版改变什么

- 本地规划目录、覆盖说明、Skill 锁文件或开发依赖不再被单独当作“这是开发仓库”的证据。真正的私密开发身份与目标包的纯净边界仍然核对。
- 缺少看板快照时可以从正式资料重建。快照缺失、损坏或两份不一致只影响看板刷新，不拒绝已经有效的核心和会话接续；问题仍会明确报告。
- 私密资料导入并回读成功后，临时清理失败只提示遗留目录；重试不会重复覆盖已经导入的资料。
- 看板无法读取资料时仍可复制一段只读排查请求。修改类按钮继续核对实例身份，不向未知助手发送写入请求。
- 任务召回不再因为用户禁止一项无关操作而把相关的本地资料一并排除。README 的版本、入口和素材说明同步更新，检查不锁死介绍原句。

## 哪些保持原样

实例身份、习惯、记忆、能力、SOP、经验、学习候选、Skill、工作区、本机绑定、私密内容和未知文件都由实例自己管理。本版没有删除用户资产或重新部署组件的步骤；不执行未知规划文件、用户脚本或本机软件。

升级后运行这次事务返回的接续命令，再通过一项相关的无破坏行为确认结果。例如：让当前 Agent 用日常说法找回一项已有任务；看板异常则单独修复或重建其快照。不需要为采用新版强制开新会话，也不要把所有开发检查交给用户实例。

支持来源和精确所有权见 `release-manifest-2.0.11.toml`。本版维持电脑端网页看板，不包含暂停中的桌面客户端，不要求手机端验收；个人写作风格专用功能继续取消，通用学习与资产能力不受影响。
