# 升级到 AI Carry 2.1.1

2.1.1 修复通用看板的两项问题：已批准 SOP 等积累可以生成正确的使用请求；复制没有及时返回结果时，可以选中全文手动复制。网页版与客户端使用同一套修复。

沿现有“检查并升级 AI Carry”入口查看并确认针对本实例的升级预览。保留实例身份、原有批准记录、记忆、SOP、能力、Skill、专业工作区和本机/私密资料；不用重新批准已有 SOP，也不重写其正文来适应页面。

文件升级后继续当前会话，并从“我的积累”打开一项已批准内容，核对生成的请求与实际用途一致。复制以真实回执为准；未确认时按页面提示手动复制，不因此回滚有效核心或停止其他任务。

需要更新客户端时，使用同一正式 Release 的对应系统应用包，按 INSTALL.md 保留并绑定原助手目录。客户端是可选入口；未安装新版应用不妨碍从本实例的 dashboard.html 使用新版网页。只优先支持电脑端，不以手机排版作为升级失败理由。
