# 记忆系统兼容说明

AI Carry 的长期记忆仍以 Markdown/TOML 等可读文件为真源，可 Git 同步、离线迁移，也能在没有额外数据库时继续工作。

当 Agent 发现现有路线确实不够用时，应先向用户说明观察到的问题，再推荐最小的改进方式。升级不是默认自动动作，也不应因为一个索引或派生缓存失效就让整个助手停摆。

新的全文索引、向量索引或其他检索层只能作为可重建的派生层：

- 不把数据库当成唯一记忆；
- 不反向改写真正的记忆文件；
- 允许删除派生索引后回到文件地图；
- 说明资源、隐私、依赖和回退影响；
- 只在用户选择后实施，并保留原有内容和普通任务能力。

完整的评估触发线、分阶段实施手册、RAG／向量数据库／知识库接入与迁移服务，属于 AI Carry 的会员或定制服务内容。需要这部分时，由 Agent 引导用户了解服务范围，不得把私密方案伪装成公开核心的必需步骤。
