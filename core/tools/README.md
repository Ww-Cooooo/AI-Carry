# 按需确定性工具

这里的工具不是普通启动依赖，也不会在后台运行。只有对应任务已经命中、宿主具备运行条件，并且用户已经授权本地动作时，Agent 才按协议调用它们；缺少运行环境时由宿主说明并选择等价的本地实现，不要求普通用户自己打开终端。

## `private_data_migration.py`

这是一个仅使用 Python 标准库的、本地有限范围参考实现，用于验证“登记资料根中的业务数据 + 由稳定 `private.*` 引用解释的私密正文”的单包导出、校验、导入预览和事务式恢复。它具备以下边界：

- 必须通过 `--policy` 明确指定当前实例或专业扩展已经登记的迁移策略；不会扫描 `workspace/` 猜测策略，也不会扫描整台电脑；
- 逻辑引用来自策略旁的路径契约，形式为 `ac-path:<scope>/<relative-path>`，不写死行业名称、盘符或旧设备绝对路径；
- 疑似秘密只返回位置、类别和数量，不返回命中值；可检查文本会做内容检查，不透明二进制只报告数量，不能被误称为已经证明内部没有秘密；可执行文件、迁移容器内的嵌套压缩包、链接、越界路径和异常压缩失败关闭；
- 多文件导入先暂存并保存旧字节，中断后整组回滚；损坏事务记录保留现场，不当成空状态覆盖；
- 已写入并回读通过后，临时目录清理失败只报告待清理，不撤销资料或要求重新导入；重试也不把已完成事务当成半写入状态；
- 工具只处理策略限制内的单个私密包。超过文件数、单文件或总字节限制，或需要 Migration Kit Schema 2.0 的多分卷／分块时，宿主必须转入完整迁移协议，不能降低标准或假装完成。

空白模板只携带工具、Schema 和空生成模板，不创建迁移策略、专业工作区或私密目录正文。示例模板位于 `core/templates/privacy/`；实例化后也只有在登记、导出、导入、换机、移动资料根或外部输入重绑时按需加载。
